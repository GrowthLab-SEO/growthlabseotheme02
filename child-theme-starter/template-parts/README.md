# Template part overrides

A file here replaces the parent template part with the same name, e.g. `template-parts/footer-form.php`.

Copy the parent file first and keep reading the same `$args`: CHILD-THEMES.md in the parent theme lists the arguments
each template part receives and which ones are kept for compatibility. An override doesn't get the fixes made later
to the parent file, so override only the template parts you need.
