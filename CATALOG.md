# Catalog: growthlabseotheme02

Generated by `tools/catalog.js` from the theme files (`npm run build` runs it). Don't edit it by hand: change the blocks, the field groups or the block descriptions (`description` in each block.json) and build again.

What a site built on this theme can contain. A design that needs something not listed here follows the decision ladder in AI-RULES.md.

## Blocks

Every block has these properties, so they are not repeated below: `toggle_block` (the block prints only when it is on; a block can be kept in a page turned off until its content exists), `block_id` (the section's HTML id, used as an anchor and to target the section in CSS), `extract_block_from_content` and `place` (move the section out of the content column, before or after it, on pages with a sidebar). Blocks also take the editor's Additional CSS class.

## Shortcodes

They work in WYSIWYG fields and in the post content, not in Link, Text or URL fields (a button of a Link field can't follow Site Options: put the link in a WYSIWYG field with the shortcode instead, styled with its class attribute, e.g. `link_class="btn btn--primary"`).

- `[phonenumber]`: prints the Main Phone Number of Site Options as a tel: link, so the number shown in the content follows Site Options. Attributes: link_class (classes of the link, e.g. "btn btn--primary" for a button), link_id, wrapper (element around the link: span, p, strong, h2...), target, and text (shown only when Site Options has no number). All attributes are escaped because any user who can edit posts (including contributors) can use it. Attributes: `target` (default '_self'), `link_id` (default ''), `link_class` (default ''), `wrapper` (default ''), `text` (default '').

## Logo symbol

The logo symbol (Site Options, `logo_symbol`) is the brand mark the theme prints as decoration. Editors replace it in Site Options and every place follows. Blocks that print it say so in their entry; template parts that print it: `template-parts/logo-separator.php`, `template-parts/team-card.php`.
